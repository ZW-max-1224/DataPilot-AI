# Phase 3: Dataset Analysis Tools

## Purpose

Phase 3 turns the profiled DataFrame into a small, safe analysis workspace. The tools are deterministic Pandas operations with validated inputs and Pydantic result contracts. They do not call an LLM, execute user-supplied Python/SQL, or open arbitrary filesystem paths. A future Agent can select from this same allowlist instead of receiving unrestricted code execution.

## Tools

| Tool | Inputs | Result |
|---|---|---|
| `get_dataset_overview` | DataFrame, dataset name, optional existing profile | row/column counts, semantic fields, missing and duplicate totals |
| `find_top_n` | column, N (1–100), order, optional group | top rows or sum-ranked groups |
| `calculate_group_statistics` | group, metric, aggregation, ordering, limit (1–100) | grouped sum/mean/median/min/max/count |
| `calculate_time_series` | date, metric, aggregation, day/week/month/quarter/year | period aggregates, change, heuristic trend |
| `analyze_missing_values` | DataFrame | per-column missing counts and rates |
| `analyze_duplicates` | example limit (0–10) | exact duplicate count/rate and bounded examples |
| `detect_outliers` | numeric column | IQR fences and at most ten sample values |
| `calculate_correlation` | two numeric columns | pairwise-complete Pearson correlation and interpretation |
| `create_chart` | line/bar/scatter/histogram and column names | Matplotlib figure and chart metadata |

`app/tools/registry.py` is the sole name-to-function allowlist. `invoke_analysis_tool` rejects names outside that registry and returns a structured success/error envelope. It is the intended future Agent boundary. Streamlit calls the functions directly today.

## Data and safety rules

- Pydantic request models reject unknown fields and constrain numeric limits and enums.
- Column references must exist; numeric operations reject categorical fields and non-finite values.
- Date parsing requires at least 80% of non-null values to parse. Excluded rows count the union of invalid-date and missing-value rows, not their sum.
- Time-series `sum` leaves all-null periods empty rather than reporting a false zero.
- Outliers use Tukey fences: below Q1 − 1.5×IQR or above Q3 + 1.5×IQR. This is a screening heuristic, not proof of bad data.
- Trend labels compare endpoints with a 5% normalized tolerance and require 60% of adjacent moves to agree. Sparse or noisy data can be labeled `mixed`.
- Pearson correlation uses complete pairs and requires variation in both fields. Correlation does not imply causation.
- Charts sample scatter plots above 2,000 points, cap displayed categories/groups, and only accept column names; they never evaluate code.
- Results are JSON-safe and examples are bounded to keep UI and future API responses manageable.

## UI

Choose **Use demo data** to load the deterministic synthetic sales CSV. The Analysis Playground exposes Top N, group statistics, time series, quality checks, and four chart types. Choose **Upload file** for your own CSV/Excel. Results stay in the current Streamlit session and reset when the active dataset changes.

The overview reuses the Phase 2 profiler rather than recomputing its own quality rules. Pandas remains the numeric source of truth; no analytics claim is generated by an LLM in this phase.

## Tests

`tests/test_analysis_tools.py` covers valid calculations, invalid columns/parameters, missing dates, malformed input, tool allowlisting, charts, and bounded output. Tests use local DataFrames and synthetic data only; they require no network or LLM key.
